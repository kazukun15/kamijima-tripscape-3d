# 上島町 3D観光WEBGIS マスター仕様書
Version: 0.1
Working title: KAMIJIMA TRIPSCAPE 3D

## 1. 目的
上島町全域を対象に、観光地、景観、歴史文化、自然、アート、港、海岸、体験、食、宿泊、移動を「3D地形上で探索できる観光WEBGIS」として構築する。

単なる観光スポットのピン地図ではなく、
- 地図から場所を発見する
- 場所から歴史・文化・人物・季節・周辺地点へ深掘りする
- 関連地点を辿って次の目的地を発見する
という「探索型デジタル観光図鑑」を目標とする。

前回の上島町災害WEBGISで採用した思想を継承する。
- Map First
- PC: ドラッグ移動、Ctrl+左ドラッグで回転・傾斜
- Mobile: タッチ操作＋Bottom Sheet
- 位置未確認データを推測配置しない
- 出典、基準日、確認状態を保持する

## 5. 事実性ルール
ハルシネーション禁止。
以下を必須フィールドとする。
- source_urls[]
- last_verified_at
- verification_status
- coordinate_source
- content_date / reference_date
- confidence_score

verification_status:
- official_verified
- multi_source_verified
- coordinate_verified
- approximate_area_only
- pending
- rejected

位置が確認できないPOIは地図に推測配置しない。
`pending` として調査台帳に残す。

## 6. 技術構成
推奨:
- Next.js or Vite + React + TypeScript
- MapLibre GL JS
- Turf.js
- GeoJSON
- 必要に応じて PMTiles / Vector Tiles
- 静的JSONによるPOI Knowledge Base
- GitHub Pages / Cloudflare Pages対応

### 3D地形
MapLibreのterrain/raster-demを使用する。
国土地理院の標高データを利用する場合は、MapLibreが扱えるDEM形式との整合を確認すること。
GSI DEM PNGをそのままMapbox Terrain RGBだと決めつけない。
必要ならビルド時にMapLibre互換DEMへ変換するか、`custom` encodingの適合性を検証する。

要件:
- terrain ON/OFF
- hillshade
- pitch 0〜80度程度
- bearing rotation
- 標高強調は原則1.0、UIから調整可能にしてもよい
- 地形読み込み失敗時は2Dへフォールバック
- attribution必須

### 建物
OSM等に高さ情報がある建物はfill-extrusionで簡易3D表示。
高さ不明建物を勝手な高さで重要建築物として表現しない。

## 11. Context Engine
生成AIがなくても動作することを基本とする。

入力:
- 選択POI
- 現在の島
- 現在の季節
- 移動手段
- ユーザーの閲覧履歴
- 選択カテゴリ
- 時間帯

出力:
- 次に見るべき地点
- 関連テーマ
- Deep Dive表示順
- おすすめ散策ルート

例:
「積善山」閲覧
→ 桜 / 展望 / 岩城島 / 歴史 / レモン / 近隣港
をスコアリングし次候補を提示。

AIは将来拡張。
APIキーをフロントエンドに埋め込まない。

## 15. 調査工程
### Phase A: Inventory
公式観光サイトの一覧、島ページ、パンフレットから候補を全件抽出。
重複を統合。

### Phase B: Verification
各POIについて:
- 正式名称
- 島
- 緯度経度
- カテゴリ
- 説明
- 歴史
- 文化財指定
- アクセス
- 営業/公開条件
- 季節
- 出典
を確認。

### Phase C: Coordinate Verification
位置は以下の順で確認:
1. 公式掲載座標/地図
2. 公的地図
3. OSM
4. 複数資料の整合

不一致は推測で確定しない。

### Phase D: Build
調査完了を待たず、
「検証済みデータからアプリ実装を並行開始」する。
調査だけで作業を終えない。

### Phase E: QA
- POIクリック
- 3D表示
- モバイル
- 検索
- Deep Dive
- 出典
- URL共有
- 404
- 読み込み失敗
- WebGL非対応
をテスト。

## 16. Definition of Done
以下すべてを満たすまで「完了」と報告しない。
- `npm install`成功
- `npm run build`成功
- 初期画面が表示
- 3D terrain表示
- 2D fallback表示
- 全主要島を地図から選択可能
- 検証済みPOIが表示
- POI詳細が開く
- Deep Diveが開く
- 出典が確認できる
- 検索が動く
- モバイルUIが破綻しない
- 未検証地点は公開レイヤーに混入しない
- READMEにローカル起動方法を記載
- 調査ログを保存
- GitHub Pages/Cloudflare Pagesのどちらかで公開可能

## 17. 禁止事項
- 調査結果だけ提出して終了
- 座標の推測
- 存在しない観光地の生成
- 公式情報と推測の混在
- APIキーのコミット
- Google Maps等の利用規約違反データ抽出
- 出典なし説明文を事実として表示
- 「あとで実装」として主要機能を未実装のまま完了扱い
