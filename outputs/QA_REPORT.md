# KAMIJIMA TRIPSCAPE 3D 検証報告

最終レビュー日: 2026-10-13 (JST)

## 今回の修正

- 低い画面で地点一覧が高さ0になる／画面外に切れる不具合を修正。検索条件と一覧を独立してスクロール可能にし、一覧を初期状態から表示。
- 地点詳細が地図操作を覆う不具合を修正。文字サイズ・コントラスト・タップ範囲を拡大し、詳細シートの高さと操作位置を調整。
- DEM読み込み後に選択ピンが持ち上がり、表示設定に隠れる不具合を修正。自動カメラ移動後の描画完了時に補正し、手動操作では補正を停止。
- 2Dの初期表示でも傾斜48度が残る不具合を修正。2Dは0度を維持。WebGL不要のLeafletでも共通の拡大・縮小を利用可能にした。
- ブラウザーの戻る／進む、共有直前の検索語、検索で古い詳細が残る状態、しおりの重複・空表示・モバイル導線を修正。
- 地点名から詳細を開けるようにし、ピンのDOMを保持してちらつきとフォーカス消失を軽減。ラベルの実寸と既存の配置を使い、空き領域の境界を探して余白を確保。
- 320px幅では地図の表示設定を開閉式にし、全域表示の島名ボタンを検索パネルに集約。観光スポット18地点の名前を優先して表示。
