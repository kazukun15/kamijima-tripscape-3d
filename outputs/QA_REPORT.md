## ブラウザー検証の範囲

デスクトップ1440×1000とPixel 7の画面・タッチ設定で同じ主要操作を検証しています。ChromiumのソフトウェアWebGLを使用しました。物理スマートフォンでの計測ではありません。

| 確認項目 | 判定に使った操作・証拠 |
| --- | --- |
| 実3D地形 | MapLibre terrain有効、実API `queryTerrainElevation` で積善山の代表地点の標高が20m超、描画スクリーンショット |
| 8島の全域表示 | 島ラベル8個がビューポート内。各ラベルを実際にクリックし、島名と件数が切り替わる |
| POI | 公開18件のマーカー。検索結果0件ではマーカー0件。pendingをGeoJSONに含めない |
| 視点 | 傾斜75度、北上への復帰、3D→2D→3Dとpitch・terrainの実値 |
| 検索 | 島・レモン・カテゴリ・キャンプ・存在しない語・リセット。スマートフォンでも全カテゴリを選べる |
| 漫画の島 | 「漫画」から公式紹介付き高井神島へ。個別壁画の未確認ピンを作らない |
| 詳細・深掘り | 岩城郷土館の人物・歴史・出典・確認日・関連テーマ・関連記事 |
| しおり | 保存後のリロードでも維持。現在地をlocalStorageに保存しない |

## 地形データの検証

国土地理院DEM PNGからTerrain RGBへ366タイルを変換。取得成功170タイルのすべての有効画素で、元標高とデコード後の誤差が**0.05m以下**。標高強調1.0。元DEM404の196タイルと元タイル内の無効値は表示用0m平面です。実測の海底・地盤標高とは扱いません。淡色地図もz8〜14の366タイルを保存し、施設拡大時の文字の解像度を確保しました。

数値の符号・無効値・変換規則は地理院仕様に合わせています。独立した測量資料による全タイルの標高監査は未実施です。
